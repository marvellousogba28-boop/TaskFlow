 TaskFlow — Smart To-Do & Reminder App

A clean, lightweight to-do list web application that helps users organize daily tasks by priority and sends automatic reminders 1 hour before a task is due.

🔗 [Live Demo]((https://6afdbd3099b44d6f3046ba30--to-do-listappp.netlify.app/))



## ✨ Features
* Custom Scheduling: Pick specific dates and due times for every task.
* Priority Tagging: Categorize tasks by High, Medium, or Low priority.
* 1-Hour Advance Reminders: Automatically triggers an alert 60 minutes before the deadline.
* Persistent Storage: Saves tasks locally in the browser so your list stays intact on refresh.

## 🛠️ Built With
* HTML5 / CSS3
* JavaScript (ES6+) 

## ⚠️ Known Limitations & Roadmap
Active Tab Requirement: Because this app runs purely client-side without a backend server, the browser tab must remain open to receive timely reminders.
